# Concepts explored through this world

Written by Codex on eresuntomatito's behalf, using the active Claude steward's requested account and the surviving project record. Luis's examples were not a fixed syllabus: the subject is what he actually questioned, explored, or chose—not every scientific topic that could be attached to a simulation.

## How to read the account

The active steward supplied [its own account](../../STEWARD-CONCEPTS.md), distinguishing **Choice** (Luis's recorded or current-session question/decision), **Offered** (Claude's explanation/proposal), **Outcome** (a reported result), and **Reading** (Claude's interpretation). It committed the note as local `b52bd5d` / public `779706d79ba07f16cd9d187eae79703f25d5bc0d`; the published note preserves Claude's wording. Earlier-era material known through files is not presented as the steward's personal memory. This guide is Codex's synthesis, not Luis speaking in the first person.

Implementation has its own clock. Public source `370995aba5d21eb56b8544a5989056da59a1edd2` includes deposition/geology and the revised divide, but **not** the newer dung-conservation work described as underway in the steward's account. A concept discussed or selected is not automatically a completed published rule.

## Non-events belong in the history

The tested stomach did not help in its tested world and was not applied. Great floods were parked. An apex did not appear merely because apex-enabling rules were introduced. These are part of the conceptual exploration, not missing successes to invent. See the [stomach study](../../../reports/status/2026-10-15_s789-stomach-test.md) and [apex checkpoint](../../../reports/status/2026-10-16_s1381-apex-checkpoint.md).

## What a dedicated topic page should add

The first dedicated account is [landforms, rock, and moving material](land-and-material.md): real-world references, Luis's questions, the implemented analogue, and built-versus-proposed limits.

For each supported concept, explain the real-world idea with appropriate sources, how Luis engaged with it, the exact model analogue, its simplifications, and dated evidence. The route above is an evidence-led entrance, not a claim that every topic already has a complete scientific essay. Do not infer an explicit conversation from a source-code field alone, or use the model to assert a general law of nature.
